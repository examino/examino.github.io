# 神醫系統 · Examino

面向全科診療場景的個人臨床參考庫。將病歷模板、藥物資料、即時計算及臨床工具整理在同一個介面，支援搜尋、鍵盤操作、日夜模式與離線查閱。

**[開啟神醫系統](https://examino.github.io/)** · **[開啟澳門好好吃](https://examino.github.io/macau-eat-well.html)**

## 神醫系統

以日常查閱和快速取用為核心，常用內容先顯示，較長的依據與補充資料按需展開。

| 工作表 | 主要內容 |
| --- | --- |
| 常用 | 病歷模板、臨床工具、附加資料；模板支援獨立複製「主訴＆現病史」與「體格檢查」。 |
| 藥物清單 | 成人與兒童用量、分齡方案、按體重計算、功效、適應症及安全資訊；部分藥物提供 G6PD 或其他重點提示。 |
| 疫苗＋ | 疫苗資料、接種時間表及保健品參考。 |
| 決策樹 | 依症狀與分支整理的急診評估參考。 |
| 抗菌譜 | 藥物類別與病原體矩陣，可聚焦病原體並查看相關提示。 |
| 交叉過敏 | 藥物交叉過敏矩陣，可選藥高亮對應行列並查閱標記說明。 |
| 激素 | 糖皮質激素等效劑量換算。 |
| 孕婦 | 孕期相關用藥參考。 |
| 兒童 | 年齡相關估算、生命徵象及其他兒科參考。 |
| 化驗 | 常見化驗資料與判讀參考。 |
| 澳門藥物庫 | 整合的藥物查詢資料。 |
| 筆記 | 獨立筆記工作表，支援建立、搜尋、編輯與刪除。 |

另提供收藏、最近查看及個人資料備份／匯入。個人記錄按本地帳戶分開保存；兩個帳戶目前共用臨床內容。

### 快捷鍵

| 快捷鍵 | 功能 |
| --- | --- |
| `Ctrl + K` | 聚焦目前工作表的搜尋框。 |
| `Alt + ↑`／`Alt + ↓` | 切換上一個／下一個工作表。 |
| `Ctrl + ↑`／`Ctrl + ↓` | 切換目前列表的上一個／下一個條目。 |
| `Ctrl + ←`／`Ctrl + →` | 切換本工作表的分頁，例如「病歷模板 → 臨床工具 → 附加資料」。聚焦工具版本按鈕時，可切換版本。 |
| `Alt + W` | 前往藥物清單，聚焦並選中兒童體重輸入框。 |

搜尋框與兒童體重框支援上述導航快捷鍵；筆記及其他計算欄位保留一般編輯行為。更完整的說明可在介面「更多 → 鍵盤快捷鍵」查看。

### 安裝到主畫面與離線使用

1. 先連網開啟[網站](https://examino.github.io/)，等待離線資料下載及校驗完成。
2. 在「更多」內查看安裝／離線狀態，確認顯示「已可離線使用」。
3. Android 可使用支援瀏覽器的「安裝應用程式」或「加入主畫面」；支援直接安裝時，頁面會提供安裝按鈕。
4. iPhone／iPad 可在 Safari 的分享選單選擇「加入主畫面」。

準備完成後，臨床摘要、藥物資料與本地計算可離線使用。參考文獻連結、Gemini 等外部服務仍需網絡；部分工具有特定資料或施測條件，請依各工具說明使用。

有新版時，系統會提供更新提示，由使用者確認後套用。若瀏覽器或作業系統清除了快取，需再次連網完成離線準備。

### 登入與個人資料

登入屬於前端的本地帳戶功能，不是伺服器端身分驗證，也不會將靜態臨床資料加密。登入密碼不列於本說明文件。

收藏、最近查看、筆記與部分設定保存在目前瀏覽器的本地儲存空間，沒有伺服器同步。不同裝置／瀏覽器不會自動共用；無痕模式、清除網站資料或瀏覽器限制，可能令記錄無法保留。需要長期保存時，請使用個人資料備份功能。

## 澳門好好吃

[澳門好好吃](https://examino.github.io/macau-eat-well.html)是同一倉庫內的另一個獨立網頁，提供澳門餐廳與均衡點餐參考，支援菜系篩選、價格抽籤、收藏及名稱複製。

兩個網頁各有自己的 Manifest、Service Worker 與快取命名。神醫系統的離線處理只接管自身入口和指定資源，不接管餐廳頁面；餐廳頁面使用自己的離線策略。

本倉庫目前存放可直接由 GitHub Pages 提供服務的**靜態發布檔案**，沒有後端，也沒有隨附原始 Excel、資料整理腳本及完整生成工具。神醫系統的主要內容內嵌於 HTML，不需要額外的臨床 JSON 服務或外部腳本 CDN。

### 本地預覽

直接開啟 `index.html` 可查閱內嵌的核心內容；安裝與 Service Worker 離線快取需在網站環境使用。若電腦已安裝 Python，可在倉庫目錄執行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

再開啟 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。純靜態預覽不需要安裝 npm 套件。

### 維護與更新

- 病歷模板或藥物資料更新，應先在資料來源／生成流程中完成，核對內容後再產生發布檔案；不宜直接修改 HTML 內壓縮編碼的資料片段。
- 藥物更新需核對成分、規格、單位、適應年齡、每次用量、每日頻次及計算上限，並驗證體重變更後的結果。
- **變更神醫系統的 `index.html` 或其快取資源時，需同步產生對應版本的 `sw.js` 與資源雜湊。** 離線安裝會校驗完整性，只替換 HTML 可能使新版本無法完成快取。
- 更新後檢查搜尋、複製、折疊、快捷鍵、日夜模式、手機版面及離線啟動；保留既有條目識別，避免影響收藏與最近查看。
- 兩個網頁的快取清理應僅處理各自的命名範圍，避免刪除另一個網頁的離線資料。

單純修改本 README 不需調整應用程式版本或快取雜湊。

## 資料使用範圍

神醫系統用於臨床查閱與工作流程輔助。資料與工具各有適用條件；診療及處方仍需結合病人實況、當地指引與實際產品仿單。數學換算結果不會自動核實適應症、劑型或病人的用藥適合性。

各條目內的參考來源可按需查看；第三方資料與元件的權利及授權，依各自原始聲明。
